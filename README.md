# 👕 สต๊อกร้านเสื้อผ้า (Firebase + GitHub Pages)

แอปจัดการสต๊อกเสื้อผ้าสำหรับร้านที่บ้าน — เก็บของด้วย QR, ต้นทุนเฉลี่ย, คีย์ขายเห็นกำไร-ขาดทุนทันที
ซิงก์เรียลไทม์ทุกเครื่องผ่าน **Firebase Firestore** และล็อกอินด้วย **Google/อีเมล**

---

## ✅ ส่วนที่ตั้งค่าให้แล้ว (โปรเจกต์ Firebase "bassssss")
- ใส่ Firebase config ลง `config.js` เรียบร้อย
- เปิดการล็อกอิน **Email/Password** และ **Google** แล้ว
- สร้าง Firestore Database แล้ว (ยังว่าง ไม่กระทบแอป ITSM-Portal เดิม)

## 🔲 ส่วนที่พี่บาสต้องทำต่อเอง (มี 3 อย่าง)
1. **วาง Firestore Rules** (คัดลอกจากไฟล์ `firestore.rules` — ใส่อีเมล the_basketballs@hotmail.com ให้แล้ว) → ดูส่วนที่ 1 ข้อ 5
2. **อัปโหลดขึ้น GitHub + เปิด Pages** → ดูส่วนที่ 3
3. **เพิ่มโดเมน github.io ใน Firebase** (หลังได้ URL แล้ว) → ดูส่วนที่ 4

## ฟีเจอร์
- 📦 จัดการสต๊อก + ที่เก็บของ (ชั้น/กล่อง) + แจ้งเตือนของใกล้หมด
- 🔳 สร้าง QR ต่อสินค้า ปริ้นแปะกล่อง สแกนแล้วเปิดสินค้านั้นทันที

- 🧾 คีย์ขายเห็นกำไร/ขาดทุนสด ๆ + รายงานกำไรรายสินค้า/กำไรสุทธิ
- 🔄 ซิงก์เรียลไทม์หลายเครื่อง/หลายคน (Firestore)
- 🔐 ล็อกอินก่อนใช้ เฉพาะอีเมลที่อนุญาต
- 📤 สำรอง/นำเข้าข้อมูล (JSON) + ดาวน์โหลด CSV

## ⚙️ ติดตั้งครั้งแรก (ทำครั้งเดียว ~15 นาที)

### ส่วนที่ 1 — Firebase

1. เข้า https://console.firebase.google.com → **Add project** ตั้งชื่อ เช่น `stock-shop` (ปิด Google Analytics ได้)
2. **สร้าง Web App**: ในหน้าโปรเจกต์กดไอคอน `</>` (Web) → ตั้งชื่อเล่น → **Register app**
   จะได้กล่อง `firebaseConfig {...}` — **คัดลอกเก็บไว้** (ใช้ในส่วนที่ 2)
3. **เปิดการล็อกอิน**: เมนูซ้าย **Build → Authentication → Get started**
   - แท็บ **Sign-in method** → เปิด **Email/Password** (Enable → Save)
   - เปิด **Google** ด้วย (เลือกอีเมลซัพพอร์ต → Save)
4. **สร้างฐานข้อมูล**: **Build → Firestore Database → Create database**
   - เลือกโซน `asia-southeast1` (สิงคโปร์ ใกล้ไทยสุด)
   - เริ่มแบบ **Production mode** ได้เลย (เราจะวางกฎเองในข้อถัดไป)
5. **วางกฎความปลอดภัย**: แท็บ **Rules** → ลบของเดิม แล้ววางเนื้อหาจากไฟล์ [`firestore.rules`](firestore.rules)
   - **สำคัญ:** แก้อีเมลในลิสต์ให้เป็นอีเมลจริงของพี่บาสและคนในร้าน (ที่จะใช้ล็อกอิน) → **Publish**

### ส่วนที่ 2 — ใส่ config ลงในโค้ด

เปิดไฟล์ [`config.js`](config.js) แล้ววางค่า `firebaseConfig` จากข้อ 2 ทับของเดิม (ช่องที่ขึ้นว่า `PASTE_...`)

### ส่วนที่ 3 — ขึ้น GitHub Pages

1. สร้าง repository ใหม่บน GitHub (เช่นชื่อ `stock-shop`) — จะ public หรือ private ก็ได้
   > โค้ดเป็น public ไม่เป็นไร เพราะ `apiKey` ของ Firebase ไม่ใช่ความลับ ความปลอดภัยจริงอยู่ที่ **Firestore Rules** (ส่วนที่ 1 ข้อ 5) และการล็อกอิน
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้เข้า repo (ผ่านหน้าเว็บ GitHub → **Add file → Upload files** หรือใช้ git)
3. เปิด Pages: **Settings → Pages → Build and deployment → Source = GitHub Actions**
   (ไฟล์ `.github/workflows/deploy.yml` จะ deploy ให้อัตโนมัติทุกครั้งที่ push)
   - หรือถ้าจะง่ายกว่า: Source = **Deploy from a branch** → เลือก `main` / `/ (root)` → Save
4. รอสักครู่ จะได้ URL แบบ `https://<ชื่อผู้ใช้>.github.io/stock-shop/`

### ส่วนที่ 4 — อนุญาตโดเมนใน Firebase (สำคัญ!)

กลับไป Firebase → **Authentication → Settings → Authorized domains → Add domain**
ใส่ `<ชื่อผู้ใช้>.github.io` (ไม่ต้องมี https:// และไม่ต้องมี path)
> ไม่งั้นปุ่มล็อกอิน Google จะขึ้น error `unauthorized-domain`

เสร็จแล้ว! เปิด URL → ล็อกอิน → เริ่มใช้ได้เลย

## 📲 ใช้งานประจำวัน
- **เพิ่มสินค้า / รับของเข้า / คีย์ขาย** จากปุ่มในแต่ละหน้า
- **ปริ้น QR**: หน้า “สินค้า” → ปุ่มปริ้น QR (ทั้งหมด) หรือในหน้าสินค้าแต่ละตัว → ปริ้น QR แผ่นเดียว
  เอาไปแปะกล่อง/ชั้น เวลาสแกนด้วยกล้องมือถือจะเปิดแอปมาที่สินค้านั้นทันที
- **แชร์ให้คนในร้าน**: ส่ง URL ให้ + เพิ่มอีเมลเขาใน `firestore.rules` (แล้ว Publish ใหม่)

## 🔁 ย้ายข้อมูลจากเวอร์ชันเดิม
ถ้าเคยใช้เวอร์ชัน Artifact มาก่อน: กด **สำรองข้อมูล (JSON)** จากของเดิม แล้วในแอปใหม่ไปที่
**ตั้งค่า → นำเข้าข้อมูล (JSON)** เลือกไฟล์นั้น ข้อมูลจะเข้ามาครบ

## 🗂 โครงสร้างไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บ + ล็อกอิน + เชื่อม Firebase |
| `app.js` | ตรรกะทั้งหมด (สต๊อก/ต้นทุน/ขาย/รายงาน/QR) |
| `styles.css` | ดีไซน์ |
| `qrcode.js` | ไลบรารีสร้าง QR (ฝังในตัว) |
| `config.js` | **ใส่ Firebase config ตรงนี้** |
| `firestore.rules` | กฎความปลอดภัย (ใส่อีเมลที่อนุญาต) |
